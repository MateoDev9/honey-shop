# HoneyShop

Landing inmersiva de miel guiada por una abeja 3D que vuela mientras se hace scroll.

- `index.html`: toda la página (HTML, CSS y JS).
- `Code/vendor/three/`: three.js 0.160.0 (MIT) y los módulos usados.
- `Code/fonts/`: Fraunces y Poppins alojadas en local.

La abeja 3D, los tarros, la miel y las animaciones se generan por código; no hay imágenes ni modelos externos. El catálogo (romero, azahar, bosque) es de ejemplo.

Para probarlo en local, sirve la carpeta por HTTP (por ejemplo `python -m http.server 8765`) y abre `http://127.0.0.1:8765/`.
